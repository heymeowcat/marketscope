## 1. Executive Summary & Core Rules

MarketScope is a high-performance self-serve trading and portfolio analytics platform. The entire platform lifecycle is governed by the **AI-Native Engineering Paradigm**:

1. **No-Hand-Coding Rule**: All production code, unit/integration tests, and database migrations must be generated by Claude Code agents. Hand-edits are strictly confined to specifications (`specs/`), `CLAUDE.md` files, agent definitions (`.claude/agents/`), hooks (`.claude/hooks/`), skills (`.claude/skills/`), and other substrate files.
2. **Spec-Is-Truth Rule**: Specifications in `specs/` are the authoritative source of truth. When code and specifications diverge, the specification must be updated and code regenerated.
3. **PR-Only Merge Rule**: No direct commits to `main`. All changes flow through agent-reviewed pull requests using `git merge --no-ff` to preserve PR history.
4. **Synthetic-Data Rule**: Only synthetic dummy data is permitted. No real customer or proprietary data.

### 2.2 Custom Commands (`.claude/commands/`)
- `/verify-ac`: Verifies all 10 Acceptance Criteria against test suites.
- `/check-role-boundaries`: Audits controller routes and security tests for CUSTOMER vs ADMIN segregation.
- `/calc-portfolio-pnl`: Validates fixed-point P&L formulas and top 5 gainer/loser algorithms.
- `/generate-feature`: Orchestrates autonomous TDD feature sprint from specification to ratchet merge.
- `/scaffold`: Initializes new components with harness conventions.

### 2.3 Custom Enforcement Hooks (`.claude/hooks/`)
- `password-hash-check.js` (`.sh`): Enforces NFR-03 (bcrypt/argon2, zero plaintext password logging).
- `role-boundary-check.js` (`.sh`): Enforces NFR-04 & NFR-08 (admin route protection).
- `executed-order-immutability-check.js` (`.sh`): Enforces NFR-02 & NFR-08 (append-only trade ledgers).
- `bigdecimal-financial-check.js` (`.sh`): Enforces NFR-01 (fixed-point Decimal.js, blocks float arithmetic).
- Plus 15 harness foundation hooks (secrets, file length, architecture, typecheck, pre-commit, sprint gate).

### 2.4 Custom Domain Skills (`.claude/skills/`)
- `crud-controller-scaffolder`: 4-tier module scaffolding with role guards and AC tags.
- `portfolio-pnl-calculator`: Fixed-point valuation, cost-basis, and P&L math.
- `watchlist-validator`: Max 10 watchlists per customer and atomic update rollback rules.
- `stats-aggregator`: Top 5 gainers & losers ranking from customer holdings.
- `archtest-author`: Codifies structural tests and layer boundaries.
- `spec-to-test-generator`: Automated generation of Vitest suites from markdown specs.

## 5. Quick-Start Guide (Running Locally)

```bash
# 1. Install dependencies
npm install

# 2. Run seed data script (synthetic users, catalog, watchlists, orders)
npm run seed

# 3. Start development server
npm start

# 4. Run test suites with coverage report
npm run test:coverage

# 5. Run architectural dependency tests
npm run test:arch

# 6. Run Playwright E2E UI tests
npm run test:e2e

# 7. Run full quality ratchet verification
npm run verify
```

## 6. How to Run with Claude Code (Work Laptop Workflow)

When pulling this repository onto the work laptop with Claude Code configured:

```bash

claude --plugin-dir .claude

# 2. To generate a feature from its specification:
/generate-feature user-management
/generate-feature stock-catalog
/generate-feature watchlist
/generate-feature order
/generate-feature portfolio
/generate-feature analytics

# 3. To run programmatic Agent SDK evaluation:
npm run agent:sprint
```
